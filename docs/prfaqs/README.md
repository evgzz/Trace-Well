# EG14Y AI Evaluation & Assurance PRFAQ Series

**Version:** 1.0 · **Date:** 2026-09-16 · **Format:** Amazon-style working-backwards PRFAQ (Press Release + FAQ)

Ten PRFAQs, one per program capability, each anchored to a concrete **customer
problem** framed for two enterprise buyer archetypes: an enterprise cloud/AI
**platform** organization (Microsoft-like) and a large **academic health system
/ payer** (Mayo-like). They are the customer-problem companions to the
whitepaper series in `docs/whitepapers/`.

> **Genre + integrity note.** Each Press Release is written in the future,
> "already-launched" voice per the working-backwards convention; these are
> internal planning artifacts, not announcements. All customer names and quotes
> are **illustrative composite personas**, not real organizations or endorsements.
> Every PRFAQ ends with a **"Current status vs. this PRFAQ"** section stating
> actual prototype maturity and claim ceilings.
