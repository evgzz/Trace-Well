# V1.6 Tier-0 hosted harness

Experimental scripts for the hosted Path A of the [real-model runbook](V1.6_REAL_MODEL_RUNBOOK.md). They automate Tier-0 transport checks against one dedicated Hugging Face Inference Endpoint. Output is `transport_only` evidence; nothing here establishes judge validity, calibration, or semantic-only FAIL authority.

This harness is a draft experiment surface. It is not part of the V1.5 or V1.6 acceptance record.

## Files

| File | Role |
|---|---|
| `scripts/tier0_admission.py` | Control-plane admission and pause; the only code that imports `huggingface_hub` |
| `scripts/tier0_codespace.sh` | Orchestrates G0–G4 in one Bash scope |
| `scripts/tier0_hf_run.py` | Builds the fixture request and runs the semantic pipeline through the adapter |
| `scripts/tier0_capture_judge.py` | Runs `hf_endpoint_judge.py` unchanged and saves wire bytes per call |
| `cases/semantic/sem-004-real-violation.yaml` | Fixture with a deterministic FAIL pair for the real judge |
| `tests/test_tier0_harness.py` | Offline tests: admission, protected paths, cleanup, payload contract |

## Environment

| Variable | Required | Notes |
|---|---|---|
| `HF_TOKEN` | yes | Codespaces secret; revoke after the run |
| `HF_ENDPOINT_NAME` | yes | Approved endpoint name for the control-plane lookup |
| `HF_ENDPOINT_NAMESPACE` | no | Owner namespace, when not the token's own |
| `HF_ENDPOINT_URL` | yes | Configured inference URL; must pass the adapter's exact-host rules against the control-plane host |
| `HF_REVISION` | yes, no default | Approved 40-character commit SHA, chosen before the run |
| `HF_API_MODEL`, `HF_ENGINE`, `RUN_ID` | no | Defaults: the Tier-0 model id, `vllm`, `tier0-qwen-hf-001` |
| `TIER0_REPEATS` | no | Adapter repetitions (default 3) |
| `TIER0_PAUSE_ON_EXIT` | no | `1` (default) pauses an admitted endpoint on exit |
| `TIER0_OUT_DIR` | no | Defaults to the ignored `results/real-model/$RUN_ID` |

`HF_EXPECTED_HOST` is never supplied by the operator. The script derives it from admission.

## Admission policy

Before any bearer token reaches the inference host, `tier0_admission.py admit` reads the endpoint from the authenticated control plane and requires:

- state exactly `running` or `scaledToZero`. `paused`, missing, unknown and all other states stop the run. The script never resumes an endpoint;
- repository equal to the runner's `MODEL_ID`, which admission reads from `scripts/tier0_hf_run.py`; the shell keeps no copy;
- revision equal to the operator's `HF_REVISION`, which must be an immutable 40-character SHA;
- an HTTPS control-plane URL, from which `HF_EXPECTED_HOST` is taken;
- the control-plane URL and `HF_ENDPOINT_URL` both passing the adapter's exact-host and origin-path rules against that host. Both normalize to the same origin, so `https://host` and `https://host/v1/` are treated as equal. `HF_ENDPOINT_URL` is checked first and only then replaced by the admitted origin.

Admission writes one JSON object to stdout. The script reads its fields with a JSON parser and never `eval`s it.

## Stages and protected paths

| Stage | Request | Token |
|---|---|---|
| G0 | branch, ignore rule, `pytest`, public-text scan | — |
| G1 admission | control-plane lookup | control plane only |
| G1 probe | `GET /v1/models` on the admitted origin, expects 401/403 | no |
| G1 wake-up | `GET /v1/models` on the admitted origin, expects 200 | yes |
| G2 | direct `POST /v1/chat/completions` on the admitted origin | yes |
| G3/G4 | runner → capture wrapper → adapter, with `--base-url` set to the admitted origin and `--expected-host` | yes |

Every `curl` uses `-q` first, `--proto '=https'` and `--max-redirs 0`. Token-bearing calls add `--fail-with-body`, and each call requires an explicit status. The adapter re-checks the host and refuses redirects independently.

Cleanup pauses only the endpoint identity returned by admission. If admission fails, the endpoint state is left unchanged. If a requested pause fails, the script writes `cleanup_failed.txt`, separate from the inference results. It then exits 3, or keeps the run's own non-zero status if the run had already failed, so automation cannot read an unpaused endpoint as a clean run.

## Offline checks

Run all four with inference credentials cleared:

```bash
(
  set -e
  unset HF_TOKEN HF_ENDPOINT_NAME HF_ENDPOINT_URL HF_EXPECTED_HOST
  python -m pytest
  python scripts/check_public_text.py
  python scripts/demo.py
  python scripts/reproduce_po9.py
)
```

The harness tests use a fake `huggingface_hub` package, a recording fake `curl`, and a `sitecustomize` that refuses every outbound socket. The `sitecustomize` also records and stops any judge process (G3/G4) before it sends anything, wherever in the script that process starts. The tests prove a protected path was not invoked from these invocation logs; missing output files are secondary evidence.

`TIER0_SKIP_SETUP=1` skips the G0 setup gates: the main-branch guard, the dependency install, `pytest` and the public-text scan. It exists so the offline tests can run the script. It is a convenience switch, not a security boundary: anyone can set it, and it does not affect admission, host binding or the request paths.

`tests/fixtures/hf_endpoint_default_payload.json` pins the adapter's default request bytes. Tests never regenerate it. A PR that changes it must explain the prompt, parameter or serialization change.

## Decision record

No new ADR. The harness applies existing decisions: credential host binding from the runbook and PR #20, judge provenance binding (ADR-0021) and semantic-judge isolation (ADR-0017). It adds no verdict semantics and changes no V1.5 behavior. If the harness is ever proposed for merge to `main`, its admission policy should be recorded as a Proposed ADR first.

## Evidence status

Any hosted runs made with earlier revisions of these scripts predate admission and host binding. They are not evidence under this procedure. No run has been performed with this version. A live run needs separate explicit authorization.
