## Purpose

This document separates **code/infrastructure integration** from **empirical semantic-judge validation**.

V1.6 implementation is now integrated into `main`. That means the semantic-evaluation capability and its evidence plumbing are integrated. It does **not** mean a real model has been calibrated, validated, or granted semantic-only FAIL authority.

## Semantic authority boundary

Until ADR-0015 is explicitly resolved in a future evidence-backed decision:

```text
global specification inconsistency -> REVIEW
deterministic FAIL                -> FAIL
deterministic REVIEW              -> REVIEW
semantic candidate PASS           -> PASS only when deterministic path is otherwise clear
semantic candidate FAIL           -> REVIEW
semantic candidate REVIEW         -> REVIEW
semantic-only SafetyFinding       -> prohibited
```

The initial 24-item Stage-B study cannot itself authorize semantic-only FAIL. Its authority-relevant outcome is limited to:

```text
STOP
REFINE
ADVANCE to a separately preregistered validation phase
```

## Merge interpretation

The V1.6 implementation merge into `main` means:

> TRACE-Well contains integrated semantic-judge infrastructure and reproducible empirical-workflow tooling, while real-model evaluation remains an explicit pending evidence milestone.

The merge does **not** mean:

- semantic-judge validity has been established;
- semantic-only FAIL authority has been granted;
- a semantic judge can create or mutate `SafetyFinding` records;
- the 24-item study has been run;
- statistical validity has been established;
- clinical validity, patient safety, regulatory compliance, or production readiness has been established.
